# TechNova

A modern and responsive **digital agency landing page** built as part of my **Front-End Development Internship at Internee.pk**.

TechNova is a fictional digital agency website created to practice responsive web design, interactive JavaScript functionality, animations, and React integration.

## ✨ Features

* Fully responsive design for desktop, tablet, and mobile
* Modern hero section with call-to-action buttons
* Interactive testimonials carousel built with vanilla JavaScript
* React-powered contact form with client-side validation
* Responsive services and project sections
* Smooth hover effects and transitions
* Responsive navigation
* Clean and modern user interface

## 🛠️ Technologies Used

* **HTML5**
* **CSS3** — Flexbox, Grid, media queries, animations, and transitions
* **JavaScript (ES6+)** — Navigation and carousel functionality
* **React 18** — Contact form component
* **Babel Standalone** — JSX compilation through CDN
